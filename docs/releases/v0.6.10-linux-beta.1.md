# BB Tools v0.6.10-linux-beta.1 — Linux BETA — NOT TESTED IN-GAME

**This separate experimental Linux desktop build has NOT been tested in-game.
Testers and feedback are needed.** It does not replace Windows stable and has
fewer features.

Version alignment only. The Windows Nightwatch adapter is unavailable on Linux. The Windows
gem-editor overhaul, NG-cycle editor, shoulder-camera and photo/flight/noclip
tools are unavailable in this Linux beta.

Included: native x64/glibc Avalonia desktop with X11/XWayland support; process
discovery and image/player validation; read-only connection by default; opt-in
health, Blood Echoes, attributes and selected resource/combat flags; launcher
support, access diagnostics, shared translations and per-session logs. A separate
always-read-only probe provides connection diagnostics.

Item spawning, native menus/warps, boss revival, multipliers, discovery/drop
hooks, FOV, Insight, free progression, presets, hotkeys, Discord and save restore
remain unavailable. No new Linux gameplay feature is introduced here.

Downloads:

- `BBTools-v0.6.10-linux-beta.1-linux-x64.tar.gz`: desktop.
- `BBTools-v0.6.10-linux-beta.1-linux-x64.zip`: identical desktop for the separate Nexus optional file.
- `BBTools-LinuxProbe-v0.6.10-linux-beta.1-linux-x64.tar.gz`: read-only probe.
- `SHA256SUMS-linux.txt`: checksums.

Archives contain only their executable and `README.md`. The desktop executable
is `BBTools.LinuxDesktop`; use `chmod +x BBTools.LinuxDesktop` if needed.

Target: native bbport, Bloodborne 1.09, x86-64 glibc. Requires X11 or XWayland;
musl/Alpine, ARM64 and Wayland-only sessions are outside this beta. Automated
platform checks do not establish live compatibility. Back up saves before
testing optional edits.

Report distro, display server, runtime version, connection result and logs through
[GitHub issues](https://github.com/JamesCicada/bb-tools/issues).
[Linux guide](https://github.com/JamesCicada/bb-tools/blob/main/docs/linux-support.md).
