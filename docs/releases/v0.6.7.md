# BB Tools v0.6.7

## New

- **Shoulder camera:** adjust the normal camera left/right, reset to centre, and retain the offset in saved/startup presets.
- **Blood-gem editor/spawner:** choose from five shapes and up to six native gem effects. Search by effect name or ID, import descriptions from your game files, or load a carried gem to create an edited copy while preserving the original.

## Validation and feedback

**Both new features are NOT TESTED IN-GAME.** Small persistent labels beside their controls make that status visible. Automated native-helper, ownership, inventory and UI checks pass, but gameplay feedback is needed on Bloodborne PC and shadPS4 before either feature is marked tested and confirmed. Please include your runtime and session log in reports.

Previously confirmed Windows features retain their existing status. Photo mode/freecam and flight/noclip remain disabled and hidden. Existing camera instability warnings still apply.

The separate **0.6.7-linux-beta.1** build remains **BETA — NOT TESTED IN-GAME** and does not include the new Windows camera/gem features. It receives version alignment and shared translations only.

Windows package: `BBTools.exe` and `README.md` only.
