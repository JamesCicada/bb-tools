# BB Tools v0.7.0

- Windows and Linux now share the gameplay backend and version number. Release automation validates both platforms before preparing one draft with Windows and Linux downloads.
- Linux desktop gains item spawning, normal/custom gem generation, travel and boss revival, Insight/NG editing, multipliers, discovery and free progression, durability tools, camera/movement tuning, target details, presets, library transfer, save tools, Discord presence and configurable X11 controls.
- Linux process selection prioritizes `bbprobe` and `bb-probe`. Launch through bbport and connect to its runtime rather than `bloodborne-bbpo`.
- Parry practice is available on both platforms with hunter protection, infinite bullets/stamina and a protected training target.

## Testing and compatibility

A community tester reported the previous experimental Linux build working through **bbport 0.7**, attached to **bbprobe**. The report did not list individual features and does not confirm the new native actions in this release. New Linux native features are **NOT TESTED IN-GAME**; feedback is needed for spawning, travel, hooks, loading transitions and cleanup. Photo mode/noclip remain experimental and opt-in; Linux controls/capture target X11/XWayland, not native Wayland windows.

Adjustable firearm-parry timing and automatic parrying remain under investigation and are not implemented in this release.
