# Nexus Mods listing — BB Tools

**Title:** BB Tools — Bloodborne Practice Companion

**Short description:** A portable Bloodborne companion for character editing, combat practice, item spawning, boss retries and travel. Supports Bloodborne PC and shadPS4. Free and open source.

## Description

BB Tools puts your next practice run a few clicks away. Set up your hunter, jump to a fight and save your favorite settings in one Windows app.

**Made with 🖤 by James Cicada.**

### Highlights

- **Build your hunter:** edit Blood Echoes and attributes, heal, use infinite stamina and consumables, or adjust damage and Echoes rewards.
- **Practice boss fights:** revive bosses, retry encounters, travel to lamps and boss entrances, and track attempts with the encounter timer. Includes The Old Hunters destinations.
- **Find your items:** spawn by ID, save favorites, or import searchable item names from your own game files.
- **Make it yours:** FOV up to 120°, camera adjustments, movement speed, saved presets and startup settings.
- **Keep your setup:** named location bookmarks, configurable hotkeys, local save backups and session logs.

### Compatibility and setup

**Bloodborne PC and shadPS4 are officially supported for CUSA03173 1.09. Tested and confirmed.** Other game builds and conflicting patches are not verified. DLC destinations require the DLC installed.

1. Extract the ZIP into a writable folder. The .NET runtime is included.
2. Start the game and load your character.
3. Run `BBTools.exe`, select the game/emulator process and connect. Auto-connect is available in Settings.

Use a separate practice save for persistent edits. Camera/FOV and exploration overrides can cause visual or performance issues. The new durability repair path still needs confirmation on both hands; ending-boss revival profiles are experimental and can change story progression.

Noclip and free camera are disabled and hidden for now. Entity inspection will return with realtime targeted-enemy updates.
