# BB Tools v0.1.0

First public release of the Bloodborne PC practice companion for Windows x64.

## Download

Download **BBTools-v0.1.0-win-x64.zip** below, extract it into its own folder,
and run **BBTools.exe**. The .NET runtime is included; no SDK or separate runtime
installation is required. `SHA256SUMS.txt` contains the ZIP's SHA-256 checksum.

**Supported profile:** native Bloodborne PC (`bb-probe.exe`), CUSA03173 1.09.
The shadPS4 live adapter is not included.

## Included

- Health, infinite stamina, Blood Echoes and all six character attributes.
- God mode, one-shot kills, stealth, silent footsteps, No AI and no fall damage.
- Combat selections retained through loading screens and warps.
- Item spawning with decimal/base or full hexadecimal IDs and linked ID references.
- 45 named lamp destinations, including all ten Old Hunters lamps.
- 19 boss entrances, including all five DLC bosses.
- Persistent named location bookmarks with same-map position/heading restoration.
- Manual or optional automatic connection and save-folder ZIP backups.

For boss entrances, travel to the area, wait for loading, then select **Go to entrance**.
Coordinate restores require the destination's map to be loaded. Travel does not
reset bosses, open doors or change quest flags. Back up saves before character edits.

## Validation and roadmap

57 automated synthetic-process checks, 25 private 1.09 instruction checks, rendered
UI inspection, and a packaged self-contained EXE startup/shutdown check pass.
The maintainer's live-game confirmations are tracked separately in
[TODO.md](https://github.com/JamesCicada/bb-tools/blob/v0.1.0/TODO.md).

Damage/Echoes multipliers, remote workshop menus, generated chalice travel and more
boss entrances are planned; they are not included in this release.
