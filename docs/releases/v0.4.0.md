# BB Tools v0.4.0

Native Bloodborne PC CUSA03173 1.09. Implemented additions are tested and confirmed,
except the weapon durability controls described below. Prepared as a draft release.

## Added

- Revival/retry for 19 base-game/DLC bosses from any loaded area, with original flag
  journals, reload, entrance placement, health/stamina refill and timer start.
- Experimental equipped-weapon repair, threshold auto-repair and keep-full controls; known issue, see below.
- Expanded presets: FOV, camera distance/height, durability, buildup and saved app/
  hotkey preferences. Independent startup FOV and startup preset opt-ins.
- Preset rename/duplicate/groups, item favorites and catalog search, library JSON
  import/export and consistent SQLite backups.
- Focused function-key hotkeys with selectable modifiers and a loading/death-aware encounter timer.
- Buildup gauge clear/keep-empty controls; active effects are not removed.
- Save backup history and CRC/path-verified restore with retained recovery copies.
- Per-session logs beside the EXE (five newest retained) and redacted diagnostics export.

## Testing and scope

The v0.3.0 baseline FOV, presets and process picker retain their confirmations.
Boss revival/retry, expanded/startup presets, hotkeys and the other implemented additions
are tested and confirmed. Details are recorded in the [checklist](https://github.com/JamesCicada/bb-tools/blob/v0.4.0/TODO.md).

**Known issue:** repair-now, threshold auto-repair and keep-full durability are not
working reliably. Further durability work is deferred to the next development session.
Use the native Workshop repair menu instead.

FOV/camera overrides are unstable and may cause performance drops and visual issues.
Use a separate practice save for boss revival: encounter flag changes can be saved.
Micolash, Gehrman and Moon Presence revival are not enabled. Advanced movement,
free camera, active-effect cures, generated-dungeon coordinate bookmarks and shadPS4
live controls remain unimplemented research, not hidden or placeholder features.

Download BBTools-v0.4.0-win-x64.zip; it contains only BBTools.exe and README.md.
SHA256SUMS.txt is a separate asset. Please report issues and contribute verified code,
UI, documentation, tests and runtime research through [GitHub](https://github.com/JamesCicada/bb-tools).
