# BB Tools v0.6.5

## Changes since v0.6.4

- **Fix damage and Blood Echoes multipliers:** the neutral effect has a zero-second
  duration and the game marks its newly inserted node expired immediately. The
  helper now validates the exact native-returned node before attaching the leased
  multiplier row, rather than skipping it and reporting a misleading player change
  or collision. Older expired effects are not revived and foreign effects remain
  protected. Distinct failure messages and log stages identify genuine ownership,
  collision, insertion and row-validation failures.
- **Fix false player-detection failures during combat:** attacks and dodges can
  legitimately take stamina below zero. Keep the player connected and display an
  empty stamina gauge instead of disabling controls. Bounded read-only retries and
  final ownership checks reject torn/loading snapshots without caching stale actors.
- **Permission guidance:** when Windows explicitly denies access to the selected
  game process, suggest closing BB Tools and restarting BBTools.exe with **Run as
  administrator**. Automatic connection also reports confirmed permission failures
  instead of silently finding nothing. Ordinary loading/partial-copy errors do not
  trigger the administrator suggestion; an accessible verified game is still preferred.
- **Translations:** Arabic and French join Simplified Chinese with **100% extracted
  UI/message catalog coverage**, including the new permission guidance. Language
  names show translated percentages. Fix Arabic percentage ordering and French tab
  wrapping. These remain community drafts awaiting native-speaker review; game
  catalog names and technical diagnostics may still appear in English. Contribute
  at [Crowdin](https://crowdin.com/project/bb-tools).

## Validation and feedback

481 regression checks pass in both Debug and Release, plus 26 script checks and
103 supported-image fingerprints. Arabic, French and Simplified Chinese each
contain all 544 current extracted catalog entries.

The zero-duration node behavior is verified against the prepared 1.09 game image;
the reporter's log repeatedly shows the same actor during the failure. Read-only
sampling on Bloodborne PC reproduced normal stamina as low as −9. Regression
fixtures model immediate native expiry, returned list indices, existing collisions,
foreign rows, resource overdraft, snapshot retries and access-denied diagnostics.

**Tested and confirmed on Bloodborne PC:** the multiplier and player-detection
fixes. Additional death/loading, startup-preset and reconnect regression testing,
plus shadPS4-specific retesting, remains welcome. Permission guidance and translation
review retain their separate validation status.
Discovery/chalice drops retain their separate pending live-test status.

Photo mode/free camera and flight/noclip remain hidden. Linux desktop support
remains in development. The ZIP contains only BBTools.exe and README.md;
SHA256SUMS.txt is a separate asset.
