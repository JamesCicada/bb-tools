# BB Tools v0.6.4

## Changes since v0.6.3

- **Discovery boost:** add 0–1000 discovery points without changing Arcane, Blood
  Level or other attributes. Existing rune bonuses remain part of the calculation.
- **Guaranteed eligible enemy drops:** remove empty outcomes from eligible enemy
  loot rolls, including the shared chalice-dungeon path. Preserve item weights and
  quantities; this does not force gem quality/effects, grant every item, bypass
  unavailable loot or change chest/scripted rewards.
- **Preset support:** save both loot options in presets, including startup presets.
  Pause bonuses during loading and restore owned instructions when disabled or
  disconnected normally.
- **Community translations:** choose a language in Settings → Preferences, with
  system-language detection, English fallback and Arabic RTL layout. All 28 project
  languages are selectable, with translation percentages beside their names.
  Simplified Chinese has a complete extracted UI/message
  draft; other languages have starter labels and need contributions. Game catalog
  names and technical diagnostics may still appear in English.
- **Help translate:** Preferences/About link to
  [BB Tools on Crowdin](https://crowdin.com/project/bb-tools). Add translator guides,
  file-based configuration and automated catalog/placeholder checks.

## Validation and feedback

467 isolated checks pass in Debug and Release, plus 26 script checks and 103
supported-game instruction fingerprints. Chinese and Arabic layouts were inspected
at the minimum window size.

**Feedback requested:** discovery and guaranteed drops have not been thoroughly
tested in-game, especially in chalice dungeons. Please report results for mobs,
bosses and gem drops with your runtime/version and session log. Synthetic checks
do not establish live chalice compatibility. Translation drafts need native-speaker
review; selectable languages are not all fully translated. Crowdin synchronization
requires its GitHub integration to be enabled and verified separately.

Photo mode/free camera and flight/noclip remain hidden. Linux desktop support
remains in development.

Extract the ZIP and run BBTools.exe. The ZIP contains only BBTools.exe and README.md;
SHA256SUMS.txt is a separate asset.
