# BB Tools v0.6.3

## Changes since v0.6.2

- **Fix movement controls:** Camera → Movement stayed disabled after connecting,
  blocking movement-speed and world-gravity toggles, sliders and restore controls.
  The panel now enables when a loaded player validates and becomes available again
  after loading screens. Inputs remain disabled while disconnected/loading.
- **Linux testers wanted:** Settings → About now says: “We need Linux testers.
  If interested, DM JamesCicada on Discord.”

Photo mode/free camera and flight/noclip remain disabled and hidden.

## Validation and feedback

The movement fix has automated UI/native regression coverage for enabling controls,
applying slider selections, loading transitions and restoring native instructions.
Validation: 410 checks in Debug and Release, plus 22 release-workflow checks.
Live retesting is pending. Please report any remaining problems with runtime/version,
reproduction steps and a session log. The Ludwig and Echoes fixes introduced in
0.6.2 retain their separate pending live-test status.

Linux desktop support remains in development; this Windows patch does not claim
Linux game compatibility.

Extract the ZIP and run BBTools.exe. The ZIP contains only BBTools.exe and README.md;
SHA256SUMS.txt is a separate asset.
