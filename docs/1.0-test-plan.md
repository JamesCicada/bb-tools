For each toggle also test off/on, death/respawn, warp/load and disconnect. Record the exact
feature, observed result and relevant session log. Stop using a failing feature and attach
its log; do not infer success for other features on the same runtime.

weapon/gem editing, camera shake/shoulder offset, jump height and cross-session chalice identity.
