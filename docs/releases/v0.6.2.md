# BB Tools v0.6.2

## Changes since v0.6.1

- **Ludwig revival:** clear his separate defeat flag and reset entry/phase state for both first-encounter and repeat modes. This addresses the script gate that disables both boss forms and the fog.
- **Multiplier cleanup:** replace infinite damage/Echoes effects with a five-second game-time effect renewed while BB Tools remains active. Interrupted sessions no longer leave a new infinite effect behind.
- **Legacy recovery:** remove recognizable leftover BB Tools effects before applying a replacement. Set both multipliers to **1** and click **Apply multipliers** with a character loaded to recover older effects. Unrelated effects are preserved; foreign collisions are rejected.
- Add recovery logging and regression coverage.

## Feedback requested

**These fixes have not been thoroughly tested in-game.** Automated validation passes
(404 checks in Debug and Release, plus 96 supported-game instruction fingerprints),
but Ludwig revival and multiplier cleanup/recovery still need user feedback on
Bloodborne PC and shadPS4. The reported Echoes scaling persistence across a full
game restart has not been reproduced and is not claimed resolved.

Please report your runtime/version, reproduction steps and session log. For Ludwig,
include whether first-encounter mode was enabled and what happened at the arena.
For multipliers, check repeated application, loading, disconnect/close and a full
game-process restart.
