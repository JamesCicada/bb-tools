# Nexus Mods listing details

## Title

BB Tools - Bloodborne PC Practice Companion

## Version

0.1.0

## Short description

A free, open-source practice companion for native Bloodborne PC 1.09. Edit health,
stamina, Echoes and stats; spawn items; warp to base-game/DLC lamps and boss entrances;
save locations; and use combat utilities. Contributions welcome on GitHub.

## Main file

- Display name: **BB Tools v0.1.0 - Windows x64**
- Upload: `artifacts/BBTools-v0.1.0-win-x64.zip`
- File description: **Portable Windows x64 build with the .NET runtime included.
  Extract and run BBTools.exe. Supports native Bloodborne PC (bb-probe.exe),
  CUSA03173 1.09. The shadPS4 adapter is not included.**
- Optional verification file: `artifacts/SHA256SUMS.txt`

## Requirements

- Windows x64.
- Native Bloodborne PC runtime: https://github.com/Supermedo/bloodborne_pc
- Supported game profile: CUSA03173, version 1.09.
- The Old Hunters content must be installed for DLC travel.
- No separate .NET runtime or SDK installation is needed for the release ZIP.
