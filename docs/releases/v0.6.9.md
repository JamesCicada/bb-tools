# BB Tools v0.6.9

**The gem-editor overhaul is NOT TESTED IN-GAME.** Please test one gem first and
report your runtime/version and session log. Automated checks do not confirm
the granted name, rating, actual properties, workshop behavior or save/reload.

- **Built-in gem catalog:** search 12,487 named effects without importing game
  files or using an external ID list. Browse and prepare builds offline;
  creation still requires connecting to a loaded character.
- **Normal mode:** choose from four documented obtainable families: Cursed Heavy
  Abyssal (+65 Strength scaling/+15 physical), Cursed Tempering (+27.2% physical),
  and Cursed Adept blunt/thrust (+32.6%). Eligible shapes and curse choices are
  constrained by complete recipes. This is an initial subset, not every natural gem.
- **Optional Advanced mode:** explicitly enable custom/OP combinations and the
  six-slot ID editor. Loading/importing a build never enables Advanced or grants
  an item automatically. Native ID and ownership checks remain active.
- **Preview and save recipes:** readable properties, SQLite saved builds,
  individual recipe sharing and compatible full-library import/export.
- **Simpler optional name import:** select `menu.msgbnd.dcx` directly, in any
  available game language. Import is no longer required to use the editor.
- **Translations:** English, Arabic, French and Simplified Chinese include the
  new controls and property labels. Native-speaker review remains welcome.

Validation: 638 Windows regression checks and 33 release-script checks passed;
all 12,487 catalog ID/rank/category/native-link mappings and four recipe source
fingerprints matched the privately supplied 1.09 parameters. UI layout was
inspected. These results are not in-game confirmation.

NG editing, shoulder camera and experimental photo/freecam/flight/noclip retain
their existing pending-live-test status.

The separate **0.6.9-linux-beta.1** remains **BETA — NOT TESTED IN-GAME**. This
update provides shared translations/version alignment; the Windows gem editor
is unavailable in the Linux beta.

Windows ZIP: `BBTools.exe` and `README.md` only.
