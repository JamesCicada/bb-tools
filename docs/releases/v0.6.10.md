# BB Tools v0.6.10

**Nightwatch compatibility changes are NOT TESTED IN-GAME.** Gameplay feedback
is needed on a recorded runtime release in Single-player, Host and Join modes.

- Support Nightwatch's documented item-grant observer wrapper for ordinary items
  and gems, preserving the runtime hook. Validate the wrapper, executable targets
  and original continuation; reject unknown redirects and recheck before publication.
- Improve workshop-menu compatibility: validate the selected factory and shared
  paths, so unrelated factory changes do not disable other menus. Support the
  documented Level-up observer and recheck the manager before publication.
- Improve direct chalice-travel diagnostics with exact failing addresses/bytes
  and a hint for redirected flag readers. Nightwatch's flag-remapping replacement
  remains unsupported; this update does not establish full co-op compatibility.

Validation: 654 Windows regression checks and 33 release-script checks passed.
The Linux shared-core portable checks passed on Windows; Linux syscall/live-game
testing remains separate. Synthetic native execution is not gameplay confirmation.

Existing gem-editor, NG-cycle, shoulder-camera and experimental exploration
features retain their pending in-game test status.

The separate **0.6.10-linux-beta.1** remains **BETA — NOT TESTED IN-GAME**.
Version alignment only; Windows Nightwatch compatibility is not available in Linux.
