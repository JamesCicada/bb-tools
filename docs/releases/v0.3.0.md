# BB Tools v0.3.0

Camera customization, reusable practice presets and a process picker for native
Bloodborne PC 1.09 (CUSA03173), including The Old Hunters.

Download `BBTools-v0.3.0-win-x64.zip`, extract it and run `BBTools.exe`.
The ZIP contains only the EXE and README; the .NET runtime and SQLite are bundled.
`SHA256SUMS.txt` is a separate release asset.

## Changes

- Live vertical FOV slider from 38 to 120 degrees, with automatic reversible
  in-memory unclamping above 48 degrees. No external patch or game-file edit is
  required. Reset/disconnect restores owned changes and preserves preexisting uncap.
- Save, replace, apply and delete named combat presets, including toggles, health
  refill, stamina and applied damage/Echoes multipliers. Apply explicitly while connected.
- SQLite storage for presets and warp bookmarks, with schema versioning and
  transactional migration of locations.json. The original JSON is retained.
- Search saved warp locations by name or map. Existing same-loaded-map validation applies.
- Show all enumerable processes, rank bb-probe.exe and likely game runtimes first,
  and filter by name, decimal PID or hexadecimal PID. Restricted identities remain
  visible. Connection still requires supported game-image validation.
- Separate Player, Combat, Items, Travel, Camera, Workshop and Settings pages.
- Neutral tested-and-confirmed checklist wording and an expanded prioritized roadmap.

## Validation and remaining checks

FOV, saved presets and process selection/filtering are tested and confirmed.
128 automated app checks, six automation checks, installed 1.09 instruction checks
and self-contained package startup/shutdown passed during development. CI repeats
Debug/Release checks before preparing the draft.

Database migration, location search, navigation and additional loading/cleanup edge
cases remain separately pending in the [checklist](https://github.com/JamesCicada/bb-tools/blob/v0.3.0/TODO.md).
Chalice travel and three additional boss entrances retain their pending status.
shadPS4 live controls are not implemented. Review assets before publishing this draft.
