# BB Tools v0.2.0

Expanded practice controls for native Bloodborne PC (`bb-probe.exe`),
CUSA03173 game version 1.09, including The Old Hunters.

Download `BBTools-v0.2.0-win-x64.zip`, extract it, and run `BBTools.exe`.
The ZIP contains only the executable and README. The .NET runtime is included.
`SHA256SUMS.txt` is a separate asset for checking the download.

## Added

- Infinite consumables and Quicksilver Bullets, retained through loads.
- Player damage and enemy Blood Echoes reward multipliers, 0.1–100x.
- Level-up, fortify, repair, storage, blood gem and Caryll rune menu shortcuts.
- Travel through your six existing chalice altars: choose one of nine named
  seal/layer/heart lamps from Hunter's Dream. Locked lamps are rejected.
- Micolash, Gehrman and Moon Presence entrance presets, bringing the catalog to
  22. The final two share an arena gate and require normal story conditions.
- App emblem and icon, creator footer, GitHub shortcut and manual update checking.
- Automated annotated tags and draft releases after version-bump CI passes.

Multipliers use a private player effect. Set both to 1, turn off practice toggles,
or disconnect normally to restore. Menus retain normal costs and material requirements;
close them normally in the game. Chalice travel starts in Hunter's Dream and requires a completed
ritual and does not unlock lamps. Coordinate bookmarks support fixed maps.
shadPS4 live memory support is not included.
