# BB Tools v0.6.0

## Changes since v0.5.0

- **Redesigned interface:** compact top navigation replaces the sidebar; section tabs organize Combat, Travel, Camera and Settings. Search is integrated into process, item, lamp, location and preset dropdowns.
- **Ignore hits:** native hit protection beneath God mode, with presets and original-state restoration. God mode + Ignore hits together are tested and confirmed on Bloodborne PC.
- **First-encounter boss revival:** optional intro/encounter reset, with the selected mode and original flags recorded in journals. Tested and confirmed on Bloodborne PC. Normal first-visit triggers still apply; individual multi-phase/ending profiles retain their own test status.
- **Keep Blood Echoes on death:** optional native death-penalty skip, with presets and persistence across loading. Does not refill the balance or prevent spending. Live death/bloodstain checks pending.
- **Discord Rich Presence:** optional, default on; shows Bloodborne, runtime and elapsed time. Disable in Settings → Preferences. Desktop integration awaits live confirmation.
- **Enemy details:** live lock-on tracking, retained readings after unlocking, stale snapshots after unloading, HP/stamina, buildup, effects and super-armor state. Corrected authoritative target selection and pointer diagnostics; live UI/protection testing pending.
- **Parry practice:** setup/restore, manual target survival protection and living-target HP restore. Setup is tested and confirmed; target actions await live tests. Auto-parry and adjustable parry windows remain research tasks.
- **Polling improvements:** unchanged combat/stamina flags are no longer rewritten every poll; cleared flags and loaded players still reapply selections. This is not a general renderer-crash fix.
- **Other fixes:** corrected rapid-poison cure mapping and updated icon artwork.
- **Temporarily hidden:** photo mode/free camera and flight/noclip remain disabled pending movement/HUD fixes.
