# BB Tools v0.7.0 — Linux desktop

**File name:** BB Tools v0.7.0 Linux x64  
**Upload:** `BBTools-v0.7.0-linux-x64.zip` (or the tar.gz on GitHub)  
**Destination:** https://www.nexusmods.com/bloodborne/mods/614  
**File category:** optional Linux platform download; keep the Windows download available.

Native desktop companion for bbport, with hunter/combat editing, item and gem
spawning, boss practice/travel, camera controls and saved presets. No Wine or
installed .NET runtime is required. Extract both files, make
`BBTools.LinuxDesktop` executable and run it.

**Launch through bbport and connect to bbprobe / bb-probe, not bloodborne-bbpo.**
A community tester reported the earlier preview working with bbport 0.7. The new
native gameplay features are **NOT TESTED IN-GAME** and need feedback. Share the
runtime/version and session log when reporting a problem.

Linux x64/glibc; X11/XWayland for hotkeys and experimental photo/flight controls.
Native Wayland game input/capture, ARM64 and musl builds are not provided.
If tracing permissions block attachment, use the in-app launcher as described in
the bundled README. The tool does not change system tracing policy.

Windows and Linux now share version 0.7.0 and the gameplay backend. Feedback,
translations and code contributions are welcome on
[GitHub](https://github.com/JamesCicada/bb-tools).
