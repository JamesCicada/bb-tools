# BB Tools v0.7.1

- **Keep Blood Echoes on death** now holds the verified native death-penalty reader for the whole death transition instead of relying solely on the manager byte that some bbport-derived runtimes reset before the bloodstain is committed.
- If a confirmed death still returns a lower balance, BB Tools restores the last observed living balance once. Ordinary spending, warps and normal reloads never trigger that recovery, and disabling the option restores the exact supported instructions and captured flag state.
- Shared Windows and Linux behavior; the restore is logged with the death and return balances.

## Testing and compatibility

Automated Windows and Linux checks cover the reader override, its exact restoration and the guarded recovery state machine. The yharnam-pc report still needs live feedback before this is marked confirmed; send a session log with the runtime version and a death/respawn reproduction. New Linux native features remain **NOT TESTED IN-GAME**. Adjustable firearm-parry timing and automatic parrying remain under investigation and are not included.
